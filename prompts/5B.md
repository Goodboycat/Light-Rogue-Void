# 5B — Art extraction: gallery → PNG sprites + atlas (optional sprite renderer)

You are continuing LIGHT (Light Rogue Void). Read `docs/CONVENTIONS.md` and `docs/HANDOFF.md` first. Credits are scarce: don't re-read files you don't need. All paths are relative to `LIGHT/game/` unless they start with `docs/` or `prompts/` (those are at `LIGHT/`).

## Goal
The user wants: procedural first, then side by side, then screenshot → extract PNGs. Do exactly that with Playwright in the sandbox, producing `public/sprites/<id>.png` + `public/sprites/atlas.json`. The game stays procedural by default; a flag `?sprites=1` (and a settings toggle "Sprite mode (faster)") swaps enemy/boss/projectile drawing for atlas blits.

## Read first
`docs/ART.md` (cell order), `App.tsx` gallery route, `renderer/EnemyRenderer.ts`, `renderer/Renderer.ts`.

## Steps (commit + push after each: `5B: <step>`)
1. `tools/extract-art.mjs` (Node + Playwright, `npm i -D playwright` and `npx playwright install chromium` — **devDependency only**): start `vite preview`, open `/?gallery=1&scale=2`, read `window.__GALLERY` (export from the gallery: array of `{id, x, y, w, h}` cell boxes), screenshot the canvas once, crop each box with `sharp` (or canvas) to `public/sprites/<id>.png`, write `atlas.json` `{id:{w,h,anchorX,anchorY}}`.
2. Budget: total sprites < 1.5 MB (PNG-8 where possible). If over, lower `scale`.
3. `renderer/SpriteRenderer.ts`: preload atlas, `drawSprite(ctx, id, x, y, rot, scale, tint?)`; cache tinted variants per colour in an offscreen canvas (max 64).
4. Flag plumbing: `?sprites=1` → `settings.spriteMode`; `EnemyRenderer`/`BossRenderer`/`ProjectileRenderer` check the flag first and fall back to procedural when an id is missing.
5. Itch build: inline sprites as base64 in the single-file build only if total < 1 MB, otherwise ship the `sprites/` folder next to `index.html` (update `tools/itch.sh` to copy it).
6. `npm run art` script = extract; document in `docs/ART.md`; commit the generated PNGs (they are *derived from procedural art*, allowed — note this exception in CONVENTIONS rule 4).

## Acceptance
- `npm run art` regenerates all sprites deterministically; `?sprites=1` shows the same game with blits; frame time at wave 40 improves or equals procedural.
- `npm run build` green, itch zip builds and runs.
