## Goal
Bosses must be stressful because they test reading and movement, not because they have HP. Build a reusable kit that 2C/2D use to rework all 6 bosses. Keep the "bosses can have entities roaming" idea from `docs/PLAN.md`.

## Steps (commit + push after each: `2B: <step>`)
1. `logic/enemies/BossKit.ts`: `telegraph(state, kind: 'circle'|'line'|'cone'|'ring', params, warnFrames, onFire)` storing entries in `state.telegraphs[]` (new array in `MutableGameState`); `fireBossProjectile`, `phaseOf(boss)` (100/66/33), `startPhaseShift(boss)` (72 frames invulnerable + arena pulse), `enrage(boss)` at `BOSS_ENRAGE_SEC = 150` (dmg ×2, warn ×0.7). Constants in `Constants.ts`.
2. Renderer: `renderer/TelegraphRenderer.ts` draws warn shapes (boss glow colour, white edge, fill alpha ramps 0.15→0.45), then a flash on fire. Called from `Renderer.ts` under enemies, above background.
3. Arena: on boss spawn set `state.arena = {x,y,r: 900}` at the player; draw a ring; outside it apply `VOID_BURN_DPS = 4 % maxHp/s` and an edge vignette. Clear on boss death.
4. Roaming adds: in `Logic.ts`, during a boss, spawn a pack of 3–5 wave-appropriate enemies every `BOSS_ADD_INTERVAL_SEC = 12` (cap 20 alive), spawned at the arena edge with a telegraph circle. Make the pack composition a boss hook `boss.def.addTable?`.
5. Boss HUD component `components/BossBar.tsx`: name, HP bar with phase ticks at 66/33, enrage countdown, phase label. Mount from `SurvivalGame.tsx` when `state.activeBoss`.
6. Migrate `HiveMind.ts` only to the kit as the reference implementation (keep behaviour simple: acid circle telegraphs + spawner adds). Others stay as-is for 2C/2D.
7. Write `docs/BOSSES.md` kit usage + a table template for the six bosses.
