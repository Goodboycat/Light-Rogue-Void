# Light Rogue Void

Light Rogue Void is a cosmic action-roguelike where you play as a lone spark fighting to escape the creeping entropy of the void.

## Studio

Beato Forge

## Developer

Goodboycat (Indie Game Developer / Hobbyist)

## About The Project

This game is a passion project developed by Goodboycat. Art inspired by Idle Tower Defense app. It was built with the thought of action gameplay while maintaining the importance of skill development (in a real-time way).

## Features

- Over 100 nodes to unlock in Skill Tree.
- Fight against unique enemy types and massive bosses.
- Gain abilities and grow stronger.
- story dialogue to keep intriguing.
