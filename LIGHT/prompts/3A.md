# 3A — Discovery: landmarks, shrines, relics, events, fog

You are continuing LIGHT (Light Rogue Void). Read `docs/CONVENTIONS.md` and `docs/HANDOFF.md` first. Credits are scarce: don't re-read files you don't need.

## Goal
The 3500×3500 world is empty. Give players reasons to *move and explore* without ever offering a choice menu (roguelite rule). Everything is found by walking there.

## Read first
`docs/GDD.md` Discovery section, `components/game/Constants.ts` (WORLD_SIZE), `components/game/logic/DropLogic.ts` (pickup pattern), `components/game/renderer/projectiles/EnvironmentRenderer.ts`, `components/game/logic/CameraLogic.ts`, `types.ts`.

## Steps (commit + push after each: `3A: <step>`)
1. `data/world.ts`: definitions for 6 landmarks (one per chapter: Fallen Beacon, Whisper Stones, Crystal Spire, Dead Engine, Bone Field, The Seam), 4 shrine types (Haste, Mend, Ward, Greed — one-time touch buff for the run), 6 relics (run-only passives: e.g. "Ember Core" +15 % fire dmg, "Mirror Shard" +1 dash charge), 3 events (Ambush, Lost Spark rescue, Collapsing Star).
2. `logic/WorldLogic.ts`: at run start seed `state.runSeed` (Date.now() or `?seed=`), place 3 landmarks, 2 shrines, 1 relic alcove, 1–2 events with a min distance of 600 from spawn and 500 from each other. Store in `state.world.points[]`.
3. Interaction: touching a shrine triggers it (particles + toast + one LIGHT line); a relic alcove is guarded by a mini event (ambush of 8 elites) and the relic is picked up like a drop; landmarks show a lore card (non-pausing, 4 s) once per run and add to `gameState.landmarksSeen`.
4. Render: `renderer/WorldRenderer.ts` draws points procedurally (distinct silhouettes per type, glow pulse when undiscovered + within 900 px); an off-screen arrow hint for the nearest undiscovered point for the first 2 chapters only.
5. Fog of discovery minimap: 120×120 canvas in a HUD corner showing visited cells (grid 20×20) + discovered points. Toggle in settings.
6. Relics shown in HUD as small icons; relic effects applied in `usePlayerStats`-equivalent run layer (`state.runModifiers`) read by AbilityLogic/PlayerLogic.
7. Found events: port fork `components/game/events.ts` + `logic/HazardLogic.ts` (`bash tools/fork.sh components/game/events.ts`) — Golden Mite, Essence Tide, Treasure Pylon, Ambush Ring, Meteor Shower. They are *discovered*, never chosen; min 25 s cooldown; show a 2 s caption. Strip mercy/translate/audio.
8. `docs/WORLD.md`: table of every point, event, effect, chapter.
