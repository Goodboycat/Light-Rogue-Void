## Goal
No audio in the repo yet. Build the manager now (so 6B can hook it everywhere), with Web-Audio **synth placeholders** for every SFX id, and write the complete **Ludo.ai prompt list** the user will generate by hand. Real files later drop into `public/audio/` and are picked up by id.

`docs/FORK_AUDIT.md`; fork `components/game/audio.ts` (`bash tools/fork.sh components/game/audio.ts`) — port the engine (unlock on first gesture, music cross-fade, ducking, voice limit) and strip track URLs/translate. `components/SettingsMenu.tsx`, `hooks/useGameSave.ts` (settings shape).

## Steps (commit + push after each: `6A: <step>`)
1. `game/audio/AudioManager.ts`: singleton; `init()` on first pointer/key; `play(sfxId, {vol, pitchVar, pos?})` with max 24 voices and per-id throttle (≥ 40 ms); `music(trackId, fadeMs)` cross-fade; `duck(amount, ms)`; master/music/sfx gains from settings; mute when tab hidden.
2. `game/audio/sfxIds.ts`: the full id list (≈ 45): ui_click, ui_back, ui_unlock, ui_error, player_shot, player_dash, player_hurt, player_low_hp, player_death, burst_charge, burst_fire, pickup_essence, pickup_relic, shrine_touch, landmark_reveal, enemy_hit, enemy_die_small, enemy_die_big, elite_die, affix_shield_break, wave_start, wave_special, streak_10, streak_25, streak_50, boss_arrive, boss_telegraph, boss_fire, boss_phase, boss_enrage, boss_die, arena_burn, event_start, event_end, meteor_warn, meteor_hit, ambush_ring, golden_mite, chapter_card, story_line, ending_leave, ending_stay. Music ids: music_title, music_ch1 … music_ch6, music_boss, music_ending.
3. `game/audio/synth.ts`: procedural placeholder per id family (blip, noise burst, sweep, chord) so every id makes *some* sound now.
4. Loader: `public/audio/manifest.json` `{id: "file.ogg"}` optional; when present and file loads, it overrides the synth. Missing files are silent-safe.
5. Settings: master/music/sfx sliders + mute, persisted.
6. `docs/AUDIO_LUDO.md`: for **every** id a Ludo.ai prompt (style, length, loop yes/no, mood, reference words), plus export settings (OGG 44.1 kHz, −14 LUFS music, −10 LUFS SFX, loop points), file naming = id, and the "drop files here" instructions.
