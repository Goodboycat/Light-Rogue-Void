# 8B — Balance: headless sim, 60-wave curves, boss TTK, tree cost curve

You are continuing LIGHT (Light Rogue Void). Read `docs/CONVENTIONS.md` and `docs/HANDOFF.md` first. Credits are scarce: don't re-read files you don't need. All paths are relative to `LIGHT/game/` unless they start with `docs/` or `prompts/` (those are at `LIGHT/`).

## Goal
Make the whole 60-wave arc fair and *stressful but learnable*: a fresh tree should die around wave 12–18, a full Offense arc should reach the Crimson Eclipse, a mastered tree should beat Darkness with effort. Bosses should take 60–120 s with the expected tree, never > 180 s.

## Read first
`tools/sim.mjs` (2A), `fork scripts/sim.ts` + `scripts/economy-sim.ts` for ideas (`bash tools/fork.sh scripts/sim.ts`), `components/game/Constants.ts`, `enemies.ts`, `bosses.ts`, `data.ts` (costs), `abilityConfig.ts`.

## Steps (commit + push after each: `8B: <step>`)
1. Grow the sim: a bot that moves away from the nearest enemy centroid and dashes on cooldown; run `npm run sim -- --tree=<preset> --from=1 --to=60` with presets `fresh | offense | defense | utility | full`; output a CSV per wave (time, kills, dmg taken, hp min, essence) to `out/sim/`.
2. Curves in `Constants.ts`: enemy HP/dmg/speed per wave as named functions; boss HP per chapter; essence per enemy; matter conversion; special-wave multipliers. Everything the sim tunes lives here.
3. Boss TTK: sim each boss with the expected preset; adjust HP/phase thresholds so TTK is 60–120 s; enrage at 150 s remains.
4. Tree cost curve: total matter to fill each arc; target: Offense arc complete ≈ 8 average runs, full tree ≈ 40 runs; adjust node costs in `data.ts` generator (keep ids stable!).
5. Death-cause table: the sim records top causes per chapter; patch outliers (one enemy causing > 40 % of deaths).
6. `docs/BALANCE.md`: tables from the final sim run + the targets above.

## Acceptance
