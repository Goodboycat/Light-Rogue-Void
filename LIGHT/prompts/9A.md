After beating Darkness, "stay" continues into Endless: waves 61+ scale forever, bosses return with mutators, and a shared **daily seed** lets players compare the same run (no server: seed = UTC date hash, scores local). Use the fork's 5 extra bosses as an *idea pool* only.

## Steps (commit + push after each: `9A: <step>`)
1. Endless flow: ending "stay" → `state.endless = true`, wave 61+; curves continue with `ENDLESS_SCALE(w)`; chapter palette cycles; WATCHER lines from a small endless pool every 10 waves.
2. Boss mutators: every 10 endless waves a previous boss returns with 1–2 mutators (Twin, Hasted Telegraphs, Mirror Arena, Eclipsed, Swarmed); mutator names + colours in `data/mutators.ts`. Optionally one new boss built from the fork idea pool if budget allows (kit-based, ≤ 200 lines).
3. Daily seed: `seed = hash(YYYY-MM-DD)`; menu "Daily Void" card starts chapter 1 with that seed (world points, special waves, affix rolls all seeded); local best per day stored; streak counter.
4. Leaderboard-less sharing: a "share code" string `LIGHT-<date>-<wave>-<crc>` the player can paste; a verify screen decodes it.
5. Archive: endless best wave, daily history (last 30).
