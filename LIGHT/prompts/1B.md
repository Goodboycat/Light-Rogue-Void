# 1B — Seeded skill tree + constellation layout

You are continuing LIGHT (Light Rogue Void). Read `docs/CONVENTIONS.md` and `docs/HANDOFF.md` first.

## Goal
The tree in `data.ts` uses `Math.random()`, so every device gets a different tree and saved node ids can dangle. Make it deterministic, readable, and add 6 chapter constellations unlocked by boss kills. **No in-run power picking** — this is the only progression.

## Read first
`data.ts` (whole, ~210 lines), `types.ts` (`AbilityNodeData`, `GameState.defeatedBosses`), `hooks/usePlayerStats.ts`, `components/EvolutionMatrix.tsx` (render + unlock rules), `components/SkillNode.tsx`.

## Steps (commit + push after each: `1B: <step>`)
1. Add `utils/rng.ts`: `mulberry32(seed)` + `hashString`. In `data.ts` replace every `Math.random()` with `rng()` seeded with `0x4C494748`. Node ids must be stable: `${arc}_${depth}_${index}`.
2. Layout: 3 arcs become 3 spiral branches at −90°, 30°, 150° with slowly increasing radius; clusters hang off branches at ±60°. Keep MIN_NODE_DISTANCE 80. Export `TREE_BOUNDS`.
3. Constellations: for each chapter in `CHAPTERS`, generate a 7-node cluster (`const_<bossId>_<n>`) placed on the outer rim at the chapter's angle; nodes have `requiresBoss: bossId` (new optional field in `AbilityNodeData`). Effects are themed (Hive: fireflies/projectiles; Warden: dash; Eclipse: aura/fire; Neutron: pickup/repulsion; Titan: HP/shield; Darkness: essence + a final "Twin Spark" +1 projectile).
4. `EvolutionMatrix.tsx`: nodes with `requiresBoss` not in `defeatedBosses` render as dim stars with a lock icon and tooltip "Defeat <boss> to reveal". Draw faint constellation lines between cluster nodes.
5. Save migration: on load, drop `unlockedAbilityIds` that no longer exist and refund their cost to `matter` (compute from a `LEGACY_TREE` snapshot if cheap; otherwise refund a flat 20 × count and say so in a toast).
6. Write `docs/TREE.md`: per arc list of skill nodes (title, depth, cost) generated by a small script `tools/dump-tree.mjs` (esbuild-bundle `data.ts` to node and print markdown).

## Acceptance
- Two consecutive builds print the same `docs/TREE.md`.
- Old saves load without errors; unknown ids are refunded.
- Build green; itch zip builds.

## Finish
Update README tables, write `docs/HANDOFF.md`, `bash tools/itch.sh`, upload zip as **light-rogue-void-itch**, push.
